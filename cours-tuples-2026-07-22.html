🥚 Les tuples, pour de vrai

Le cours de l'exo tisbury-treasure-hunt, mais expliqué comme à un gamin de 10 ans.

Clique sur chaque bloc pour le déplier. Avance une brique à la fois — pas besoin de tout lire d'un coup. À la fin de chaque section, un petit quiz pour vérifier que c'est rentré.

1 C'est quoi un tuple ? ▶
🥚 L'image : un tuple, c'est une boîte d'œufs scellée. Une fois fermée, tu ne peux ni ajouter, ni enlever, ni remplacer un œuf. L'ordre est figé pour toujours.

À l'opposé, une liste c'est ta trousse 🎒 : tu ajoutes un stylo, tu en enlèves un, tu réorganises — quand tu veux.

Ce mot compliqué pour "on peut plus le changer" : immuable. Un tuple est immuable. Une liste, non.

On reconnaît un tuple à ses parenthèses ( ). C'était ta question de tout à l'heure — voici les 3 boîtes de Python :

SymboleNomOn peut le modifier ?Ça sert à…
( )tuple❌ non (scellé)des données figées, dans l'ordre
[ ]liste✅ ouiune collection qui bouge
{ }dict / set✅ ouipaires clé: valeur (dict) ou éléments uniques (set)
✅ Dans ton exo Chaque record comme ('Scrimshawed Whale Tooth', '2A') était un tuple. Tu ne l'as jamais modifié — tu as juste lu dedans. Normal : il est scellé.
🤔 ('chat', 'chien') — tuple ou liste ? Et est-ce que je peux y ajouter 'oiseau' ?
C'est un tuple (parenthèses). Et non, tu ne peux pas y ajouter 'oiseau' : il est scellé. Il faudrait en construire un nouveau.
2 Construire un tuple ▶

Deux façons de fabriquer une boîte scellée.

Façon simple (le littéral) — tu écris juste les valeurs entre parenthèses :

# Tu poses les œufs, tu ferme la boîte
fruits = ("pomme", "kiwi", "guava")

Façon usine (le constructeur tuple()) — tu donnes une collection existante et il la transforme en tuple :

tuple(["pomme", "kiwi"])   # une liste -> un tuple
⚠️ Piège n°1 — le tuple à UN seul élément Pour une boîte avec un seul œuf, la virgule est obligatoire, sinon Python croit que ce sont juste des parenthèses de calcul. 
une = ("guava")    # ❌ ça, c'est juste le texte "guava"
une = ("guava",)   # ✅ ÇA, c'est un tuple à 1 élément
⚠️ Piège n°2 — donner un mot à tuple() Un mot (string), pour Python, c'est déjà une suite de lettres. Si tu le donnes au constructeur, il éclate le mot lettre par lettre : 
tuple("chat")
# -> ('c', 'h', 'a', 't')  😱 pas ce que tu voulais
🤔 Que vaut ("solo") ? Et ("solo",) ?
("solo") = juste le mot "solo" (pas un tuple). ("solo",) = un tuple d'un élément. Toute la différence est dans la virgule.
3 Des boîtes dans des boîtes ▶
📦 L'image : une boîte scellée peut contenir n'importe quoi — même d'autres boîtes, ou un tiroir (dict), ou une trousse (liste).

C'était ta question sur cette ligne. On la lit de l'extérieur vers l'intérieur :

donnees = ({"fish": "gold", "monkey": "brown"}, ("fish", "bird"))
(  {...dict...}  ,  (...tuple...)  )
└─ les ( ) autour = 1 TUPLE de 2 éléments
   ├─ élément 0 : { "fish":"gold", ... }  -> un dict (il y a des « : »)
   └─ élément 1 : ( "fish", "bird" )      -> un tuple

Le signal : = dict. Pas de : dans des accolades = set. Les parenthèses = tuple.

🤔 (["a", "b"], "c") — combien d'éléments dans le tuple extérieur, et de quel type est le premier ?
2 éléments. Le premier ["a", "b"] est une liste (crochets), le second "c" est un string.
4 Coller deux boîtes ensemble ▶
➕ L'image : tu prends deux boîtes scellées et tu les mets bout à bout pour en faire une seule plus grande. C'est le +. 
("George", 5) + ("cat", "Tabby")
# -> ("George", 5, "cat", "Tabby")

Et le *, c'est "répète cette boîte N fois" :

("cat",) * 3
# -> ("cat", "cat", "cat")
✅ Dans ton exo Ta fonction create_record faisait exactement ça : azara_record + rui_record pour coller les deux enregistrements en un seul gros tuple.
🤔 Que donne (1, 2) + (3,) ?
(1, 2, 3) — les deux boîtes collées bout à bout.
5 Attraper un élément par son numéro ▶
🔢 L'image : chaque case de la boîte a un numéro de place (un "index"). Tu peux compter depuis la gauche (en partant de 0) ou depuis la droite (en partant de -1). 
coord = ( "2"  ,  "A" )
          [0]     [1]     <- on compte depuis la gauche (à partir de 0)
         [-2]    [-1]     <- ou depuis la droite (à partir de -1)
coord[0]    # -> "2"
coord[1]    # -> "A"
coord[-1]   # -> "A"  (le dernier)
⚠️ Le piège qui t'a eu Ça commence à 0, pas à 1. Sur "2A" (2 cases), les seuls numéros valides sont 0 et 1. Demander [2] → IndexError, la case n'existe pas.
✅ Dans ton exo get_coordinate utilisait record[-1] (le dernier = la coordonnée). convert_coordinate utilisait coordinate[0] et coordinate[1] pour séparer "2" et "A".
🤔 Sur lettres = ("x", "y", "z"), que valent lettres[0] et lettres[-1] ?
lettres[0] → "x" (le premier). lettres[-1] → "z" (le dernier).
6 Passer sur chaque élément (la boucle) ▶
🚶 L'image : tu ouvres la boîte et tu passes devant chaque case, une par une, pour faire quelque chose avec. 
for item in student_info:
    print(item)
# affiche chaque élément l'un après l'autre

Et si tu veux aussi le numéro de place en même temps que la valeur, tu utilises enumerate :

for index, item in enumerate(student_info):
    print(index, item)
# 0 Alyssa / 1 grade 3 / 2 female ...
✅ Rappel d'hier enumerate, tu l'as déjà croisé dans student_ranking (exo making-the-grade) pour avoir le rang et le nom en même temps.
🤔 Pourquoi utiliser enumerate plutôt que juste for item in ... ?
Quand tu as besoin du numéro de place (l'index) EN PLUS de la valeur. Sinon, un simple for item in ... suffit.
7 Est-ce que c'est dedans ? ▶
🔍 L'image : tu demandes "est-ce que cet œuf est dans la boîte ?" et Python répond juste oui (True) ou non (False). 
animaux = ("Parrot", "Bird")
"Parrot" in animaux   # -> True
"Cat" in animaux      # -> False
🤔 3 in (1, 2, 4) renvoie quoi ?
False — 3 n'est pas dans la boîte.
