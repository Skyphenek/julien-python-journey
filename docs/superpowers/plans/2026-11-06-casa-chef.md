```python
"""Le chef de la Casa : la file des recettes à améliorer, la lecture et l'écriture sans risque (06/11/2026).

La rédaction (trucs, gestes, secrets de Julien) vit dans le skill chef-casa ; ici, seulement les données.
Neon fait foi : on lit la version du jour, on sauvegarde l'ancienne, on n'écrase pas une correction faite dans l'app.
"""

MARQUEUR = "Ce qui fait la différence"     # le bloc final : sa présence veut dire « déjà passée »
_ORDRE_GENRES = ["plat", "accompagnement", "entree", "dessert"]


def file_de_passage(conn, n=5):
    """Les n prochaines recettes : les plus cuisinées d'abord, puis le carnet, puis le genre, puis le nom."""
    with conn.cursor() as cur:
        cur.execute(
            """SELECT p.id, p.nom, p.genre, p.statut,
                      (SELECT count(*) FROM repas r WHERE r.issue = 'fait' AND r.plats ? p.id) AS faits
               FROM plats p
               WHERE NOT p.archive AND position(%s IN p.recette) = 0
               ORDER BY faits DESC, p.statut = 'a-tester', array_position(%s, p.genre), p.nom
               LIMIT %s""", (MARQUEUR, _ORDRE_GENRES, n))
        return [dict(zip(("id", "nom", "genre", "statut", "faits"), ligne)) for ligne in cur.fetchall()]


def lire(conn, id_):
    """La recette du jour, avec son maj_le (à rendre à ecrire)."""
    with conn.cursor() as cur:
        cur.execute("SELECT id, nom, genre, pour, recette, maj_le FROM plats WHERE id = %s", (id_,))
        ligne = cur.fetchone()
    return dict(zip(("id", "nom", "genre", "pour", "recette", "maj_le"), ligne)) if ligne else None
```

Note : `array_position(%s, p.genre)` reçoit une liste Python, que psycopg2 passe en `text[]`.

```python
class RecetteModifiee(Exception):
    """La recette a changé dans l'app depuis la lecture : relire et reproposer."""


def _chemin_libre(dossier, id_):
    base = f"{datetime.now(ZoneInfo('Europe/Paris')).date().isoformat()}-{id_}"   # date de Paris, comme casa.py
    chemin, i = dossier / f"{base}.json", 2
    while chemin.exists():                           # une sauvegarde n'est jamais écrasée
        chemin, i = dossier / f"{base}-{i}.json", i + 1
    return chemin


def ecrire(conn, id_, texte, maj_lu, dossier):
    """Sauvegarde l'ancienne version dans dossier, puis remplace la recette. Rend le chemin de la sauvegarde."""
    if MARQUEUR not in texte:
        raise ValueError(f"le bloc « {MARQUEUR} » manque")
    with conn.cursor() as cur:
        cur.execute("SELECT nom, recette, note, maj_le FROM plats WHERE id = %s FOR UPDATE", (id_,))
        ligne = cur.fetchone()
        if ligne is None:
            conn.rollback()
            raise KeyError(id_)
        nom, recette, note, maj_le = ligne
        if maj_le != maj_lu:
            conn.rollback()
            raise RecetteModifiee(f"{id_} modifiée le {maj_le.isoformat()}, lue le {maj_lu}")
        dossier.mkdir(parents=True, exist_ok=True)
        chemin = _chemin_libre(dossier, id_)
        chemin.write_text(json.dumps({"id": id_, "nom": nom, "recette": recette, "note": note,
                                      "maj_le": maj_le.isoformat()}, ensure_ascii=False, indent=1))
        cur.execute("UPDATE plats SET recette = %s, maj_le = now() WHERE id = %s", (texte, id_))
    conn.commit()
    return chemin
```

```python
def main(argv=None):
    arguments = argparse.ArgumentParser(description=__doc__.splitlines()[0])
    arguments.add_argument("--base", default="valise")
    commandes = arguments.add_subparsers(dest="commande", required=True)
    commandes.add_parser("file").add_argument("--n", type=int, default=5)
    commandes.add_parser("lire").add_argument("id")
    e = commandes.add_parser("ecrire")
    e.add_argument("id")
    e.add_argument("fichier", type=Path)
    e.add_argument("--maj", required=True, type=datetime.fromisoformat)
    e.add_argument("--dossier", type=Path, default=SAUVEGARDES)
    options = arguments.parse_args(argv)

    conn = connecter(options.base)
    try:
        if options.commande == "file":
            for p in file_de_passage(conn, options.n):
                print(f"{p['faits']}\t{p['id']}\t{p['nom']}\t{p['statut']}")
        elif options.commande == "lire":
            r = lire(conn, options.id)
            if r is None:
                print(f"inconnue : {options.id}", file=sys.stderr)
                return 1
            print(json.dumps(r | {"maj_le": r["maj_le"].isoformat()}, ensure_ascii=False, indent=1))
        else:
            texte = options.fichier.read_text().rstrip("\n")
            try:
                print(ecrire(conn, options.id, texte, options.maj, options.dossier))
            except RecetteModifiee as erreur:
                print(f"modifiée entre-temps, relire : {erreur}", file=sys.stderr)
                return 2
            except (KeyError, ValueError) as erreur:
                print(f"refusé : {erreur}", file=sys.stderr)
                return 1
        return 0
    finally:
        conn.close()


if __name__ == "__main__":
    load_dotenv(Path(__file__).parent / ".env")     # en local : DATABASE_URL de voyage/.env -> Neon
    sys.exit(main())
```

````markdown
# Chef de la Casa

But : le « petit truc qui fait la différence », écrit dans la recette elle-même, lisible sur l'iPhone en cuisine.
Spec : `docs/superpowers/specs/2026-11-06-casa-chef-design.md`. Toutes les commandes se lancent depuis `voyage/`.

## Déroulé d'une session (5 recettes au plus)

1. `.venv/bin/python chef.py file` : montre les 5 prochaines (colonne 1 = fois cuisinée). Julien garde, retire, ou
   impose une recette (`chef.py lire <id>` directement).
2. Pour chaque recette, une à la fois :
   a. `.venv/bin/python chef.py lire <id>` ; garder `maj_le`.
   b. Demander : « Tu as un truc à toi sur ce plat ? » — attendre la réponse avant de rédiger.
   c. Rédiger la nouvelle version selon les règles ci-dessous. Montrer : la recette complète (bloc de code), puis
      « Ce que j'ai changé et pourquoi » (puces courtes), puis ce qui est signalé sans être corrigé.
   d. Attendre un OK explicite. Une correction de Julien → nouvelle version complète, nouvel OK.
   e. Écrire le texte validé dans un fichier du scratchpad, puis

## Règles de rédaction

1. **Les secrets de Julien d'abord.** Marqués « (secret de grand-mère : … ) » dans l'étape concernée. Ils priment
   sur toute proposition de Claude qui les contredit. « Secret de grand-mère » est réservé aux trucs de Julien ;
   « secret de mamma » reste la convention des recettes Mamma déjà en base.
2. **2 à 4 trucs, pas plus** : assaisonnement (acide, sel au bon moment, finition), technique (saisie, réduction,
   repos, monter au beurre), ingrédient qui change tout (de préférence déjà au placard), texture et dressage.
   Un truc qui n'améliore pas nettement le résultat n'est pas proposé. Pas de débat d'école : si la version
   actuelle marche, on la garde.
3. **Test du geste** — chaque verbe d'action répond à :
   - avec quoi (spatule en bois, plat de casserole, doigts) ;
   - dans quel sens / comment (à plat comme une épingle, du centre vers les bords) ;
   - jusqu'à quel signal vu, entendu ou senti (le beurre mousse et chante, l'alcool ne pique plus le nez).
   Un temps en minutes seul ne suffit pas : il accompagne le signal.
4. **Le pourquoi dans la même phrase**, entre tirets : « — humide, la viande bout au lieu de dorer ».
5. **L'ordre suit les gestes** : si deux gestes se contredisent (eau pour aplatir / viande sèche pour dorer),
   réordonner (aplatir, puis sécher) et le dire dans l'étape.
6. **Ne bouge pas** : la liste d'ingrédients (seule une répartition : « dont 30 g froid »), les temps, les
   portions. Les « jamais » de Laetitia restent dehors (`~/brain/bin/brain recall "Laetitia goûts jamais"`).
7. **Signaler sans corriger** le hors-sujet (« Pour 4 » alors qu'on est deux) : dans la proposition, pas dans la
   recette.
8. **Bloc final obligatoire**, dernière section du texte, 3 lignes au plus :
   ```
   Ce qui fait la différence
   - <truc> : <effet dans l'assiette>.
   ```
   Un ancien bloc « Erreurs fréquentes » est absorbé par les étapes et ce bloc.
9. **Ton** : tutoiement, phrases courtes, comme les recettes existantes. Format conservé : « Pour N », liste
   d'ingrédients en tirets, étapes numérotées.
````
